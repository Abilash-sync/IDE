# IDE

## Timer Application

A beautiful and responsive timer web application built with HTML, CSS, and JavaScript.

### Features

- **Multiple Time Units**: Set hours, minutes, and seconds
- **Start/Pause/Reset Controls**: Full control over timer operations
- **Real-time Display**: Large, easy-to-read timer display in HH:MM:SS format
- **Audio Notification**: Plays a beep sound when timer completes
- **Responsive Design**: Works on desktop and mobile devices
- **Visual Feedback**: Status updates and button states change based on timer state
- **Modern UI**: Gradient background with smooth animations and transitions

### How to Use

1. Open `timer.html` in your web browser
2. Set the desired time using the input fields (Hours, Minutes, Seconds)
3. Click **Start** to begin the countdown
4. Use **Pause** to pause the timer (you can resume by clicking Start again)
5. Click **Reset** to clear the timer and start over
6. When the timer reaches zero, an audio alert will sound

### Browser Compatibility

Works on all modern browsers that support:
- HTML5
- CSS3 (Flexbox, Gradients)
- ES6 JavaScript
- Web Audio API (for sound notification)
